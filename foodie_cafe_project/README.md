# Foodie Cafe – Web Technology Project

## Project pages
- `index.html` – Home page
- `menu.html` – Menu, HTML price table and audio player
- `gallery.html` – Six-image gallery with JavaScript lightbox
- `contact.html` – Booking form, validation and embedded Google Map

## Technologies
HTML5, CSS3 (Flexbox, Grid, responsive media queries), and JavaScript.

## How to run
1. Extract the ZIP file.
2. Open the `foodie_cafe_project` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Use the navigation menu to visit all four pages.

## Features
- Shared external CSS and JavaScript files
- Semantic HTML5 structure
- Responsive mobile navigation
- Dark/light theme saved in localStorage
- Booking form with required fields and JavaScript validation
- Gallery lightbox (click a picture; press Escape to close)
- HTML table, image alt text, video, audio and Google Maps iframe
- Back-to-top button
